Deadzone — the streaming-ASR silent-failure map

Not "how much does the model break?" but does the model know it is breaking? Every panel below reads the same master results table: one row per (clip x condition x model), typed edits and per-word confidence included.

PANEL 1 — HEADLINE

Silent-failure map: where the model is confident and wrong

One point per condition: mean word confidence (x) against measured WER (y). The shaded box is the dead zone — high confidence AND high WER, i.e. the model committed to a wrong transcript instead of asking the speaker to repeat.

PANEL 2 — FACTOR SPACE

Reverb x noise: WER, with the confidence gap as a second encoding

Cell fill is WER on the shared ramp; border weight is the confidence–accuracy gap (thicker = the model claimed more accuracy than it delivered) and a red border marks a dead zone. Faceted by noise type and codec, so the channel arm can be read against the acoustic core.

PANEL 3 — MECHANISM

Failure fingerprints: what kind of error each condition family produces

Not how many errors — which kind. Each family's bar is its substitution / deletion / insertion composition as a share of reference words, with the entity error rate marked; each signature implies a specific fix, printed beside it.

PANEL 4 — ATTRIBUTION

Variance-based sensitivity and the pre-registered interaction

S1 is what a factor does alone, ST what it does in total; the ST−S1 gap is the interaction evidence. The verdict on the pre-registered rt60 x snr_db expectation is stated first — NOT CONFIRMED is a result and is shown with the same prominence as CONFIRMED.

PANEL 5 — PREDICTIVE

Active learning: mapping the failure boundary in fewer evaluations

Step the loop: the heat is the GP's predicted WER over the reverb x SNR slice, and each new red point is the condition the acquisition function chose to spend an oracle call on. Below, active vs random fidelity with a min–max band across seeds.

PANEL 6 — HONEST BOUNDARY

Sim vs real: does the simulator rank conditions like the measured rooms?

Each point is one condition run through a measured RIR (x) and its RT60-matched synthetic twin (y). The level gap says how optimistic the simulator is; the rank correlation says whether it still points at the same dangerous conditions.

PANEL 7 — SECOND ARM

Do two models have the same dead zones?

A commercial streaming model against an open baseline. Confidence is comparable within a model and never across two — Deepgram returns an acoustic confidence, Whisper the decoder's token probability — so each arm is ranked against its own distribution. This panel is outside the model toggle: it is the comparison itself.

PANEL 8 — DOES THE AGENT NOTICE?

Paralinguistic features vs lexical accuracy: same rate, or decoupled?

The only layer that reads audio rather than the results table. If the two streams decouple, a system watching prosody is blind to an ASR that has already failed — or alarms on audio the ASR is still handling. Where a curve never leaves its floor, no threshold is quoted: a crossing point read off a flat normalized curve is arithmetic without meaning.

How to read this honestly. This is a controlled instrument, not a field benchmark: every input is real (measured RIRs, recorded noise, recorded speech) but the assembly is synthetic, so the value is counterfactual isolation, not fidelity to any one deployment. Behavioural factors are deliberately out of scope — accent, disfluency, speaking rate, and above all the Lombard effect: in real noise people change how they speak, and no acoustic simulator reproduces that. Panel 6 is where the simulation is asked to account for itself.

The genre is well-trodden (WildASR; Speech Robustness Bench; "When Denoising Hinders"). What this adds is the lens: the confidence–accuracy gap as the headline, typed failure fingerprints instead of a scalar, and an active-learning surrogate over the boundary.
