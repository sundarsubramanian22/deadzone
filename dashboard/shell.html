Deadzone: where a streaming ASR model is confident and wrong

Aggregate WER hides both where a model fails and how. The question this instrument asks is narrower and more useful to a deployment: does the model know it is breaking? Confidence is what decides whether a voice agent commits to a transcript or asks the speaker to repeat, so a confidently wrong model is more dangerous than one that knows it is struggling. Every panel below reads the same master results table — one row per clip × condition × model, with typed edits and per-word confidence.

How to read this honestly

This is a controlled instrument, not a field benchmark. Every input is real — measured room impulse responses, recorded noise, recorded speech — but the assembly is synthetic, so what it buys is counterfactual isolation, not fidelity to any one deployment: you turn one knob and hold everything else still, which is the one thing field recordings cannot give you.

Behavioural factors are deliberately out of scope: accent, code-switching, disfluency, speaking rate, and above all the Lombard effect — in real noise people involuntarily change how they speak, so noise does not merely mask the signal, it changes how the signal is produced. No acoustic simulator reproduces a behaviour. That boundary is exactly where real field recordings would earn their keep.

Positioning

The controlled-degradation-testbed genre is well trodden — WildASR, Speech Robustness Bench, "When Denoising Hinders", the RIR-augmentation lineage. Nothing here claims novelty of method. What this adds is the lens: the confidence–accuracy gap as the headline rather than a scalar WER, typed failure fingerprints that imply specific fixes, an active-learning surrogate over the failure boundary, and a commercial streaming model that exposes per-word confidence where the literature mostly uses open models.
